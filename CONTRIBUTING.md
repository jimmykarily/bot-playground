# Contributing

Please open an issue to describe a change before you start working on it, so we can agree on the approach first. Keep pull requests small and focused on a single change, which makes them easier to review. Run the tests before you push and mention in the pull request how you ran them.

Sign off every commit with `git commit -s`, which adds a `Signed-off-by` line certifying that you have the right to submit the change.
